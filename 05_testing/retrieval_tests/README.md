
# A04 检索测试与隔离材料

状态：测试设计，未在 XIPU AI 执行。版本：A-v0.3，2026-11-05。

本目录包含 10 条检索验收题、可执行前置条件和人工参考判断。它与 C 的功能/安全测试分开；题目、预期答案、运行记录**不上传到被测知识库**。测试前确认知识文件和项目材料的版本，记录原始命中片段与 Agent 完整回答。

## 环境与资料

| 环境 | 内容与作用 | 用例 |
|---|---|---|
| `A-ENV-MIX-v1` | 隔离测试库：`fixtures/A04_虚构课程要求.md`、`fixtures/A04_虚构项目状态.md`，以及经主搭建人选择并记录具体版本的 B03/B04 或等效通用方法。 | A-RT-01—07 |
| `A-ENV-SOFT-v1` | 单独的软件项目状态：`fixtures/A04_虚构软件项目状态.md`；可结合经确认版本的 B05。 | A-RT-08 |
| `A-ENV-CONFLICT-v1` | 另一隔离测试库：`fixtures/A04_冲突通知甲.md` 与 `fixtures/A04_冲突通知乙.md`；这两个通知无已确认先后或替代关系。 | A-RT-09—10 |

夹具均是 A 人工编写、明确标注的虚构资料，不能当作 XJTLU 或真实项目规定；也不能标为 B 已交付的 `BASE-B-v1.0` 案例。是否可在平台创建独立知识库、限制访问及保存可见轨迹，需要实际核验。

## 执行及判定

1. 固定测试对象、项目、资料版本、Agent 提示词、模型和平台实际可见设置；确保预设材料已处理。测试 A-RT-07/08 时不要额外连接包含对应答案的来源。
2. 在 Hit test 输入同一问题，记录来源文件、返回片段和可见排序。跨文件或冲突题必须检查所需双方材料能否被找到；如只运行过分开的查询，不能据此断言完整 Agent 调用已获得所有片段。
3. 将测试知识连接 Agent，提交同一输入，记录完整答案、引用及平台可见调用轨迹。单独的 Hit test 结果不等于这一次 Agent 实际接收的上下文。
4. 对照题目的可观察条件判为通过/失败/阻塞；无运行保持未执行。若需要的调用细节不可见，记录不可观察，不把推测写成执行证据。
5. 优先判断来源、解析、切块、检索、连接、实际上下文和生成哪个环节出现问题；每次仅改一个主要因素并保留原结果复测。

## 文件

- `A04_检索验收.csv`：4 条事实、2 条跨文件整合、2 条无答案、2 条冲突用例；各行均有输入、证据、预期、禁忌和空白实际记录字段。
- `A03_引用与注入识别示例.md`：三种引用回答及可疑文件指令的人工评审示例；不作为生产知识导入。
- `A08_BM25与混合检索验证方案.md`：可选检索方案与 8 个补充对照用例；暂未验证平台是否支持，也未执行。
- `fixtures/`：仅用于上述隔离场景；只有设置测试知识库时才按相应环境导入。

本轮设计数量不能用作已执行数量，也不能由此推断总体准确率或安全性。若后续统计通过率，以实际可判定的通过与失败用例为分母，单独列出阻塞和未执行数量。
