# 分工与排期
## 1. 文档目的
本模板用于工程小组项目，在任务拆解完成之后，为各项工作分配负责人、规划时间节点，平衡组员工作量，识别人员资源冲突，辅助团队制定合理时间表。

## 2. 分工分配原则
1. 结合组员个人技能去匹配对应的任务，扬长避短。
2. 尽量均衡每个人的预估工作量，避免个别成员任务过载。
3. 明确每项任务唯一主要负责人，可以设置协助人员，防止出现“人人负责，最后没人落实”的情况。
4. 任务的责任人需要知情确认，不能单方面强行分配任务。

## 3. 排期制定原则
1. 根据任务前置依赖关系确定先后顺序，前序任务完成之后后续任务才可以启动。
2. 需要预留一定缓冲时间，用来应对调试、物料延期、突发问题。
3. 标记关键里程碑节点，里程碑代表项目重大交付点。
4. 时间信息不确定时标注【待确认】，不要虚构日期。

## 4. 分工字段说明
每一条分工记录包含：
- 任务编号
- 任务简述
- 主负责人
- 协助人（可选）
- 预计工时
- 计划开始时间
- 计划完成时间
- 里程碑标记（是 / 否）
- 当前状态：未开始 / 进行中 / 受阻 / 已完成

## 5. 工作量风险提示
- ⚠️风险1：同一个人并行承担大量高工时任务，容易延期，应当重新调整分工。
- ⚠️风险2：关键路径上任务如果延期，会连锁影响后续全部工作，需要重点跟进。
- ⚠️风险3：硬件采购、外部加工类任务存在外部不可控因素，预留缓冲时间。

## 6. 小组角色参考（适配EngiMate项目A/B/C/D四人小组）
- A：资料与检索负责人
- B：方法与模板负责人
- C：测试与质量负责人
- D：用户与展示负责人

> 在实际分配任务的时候，可以按照上面四个人的岗位属性匹配对应的工作内容。
