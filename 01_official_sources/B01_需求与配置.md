# 需求与配置
## 1. 项目简述
本项目为 EngiMate（工程项目专属助手构建器），面向大学课程软硬件、机电创客小组项目。核心是通过对话收集团队项目信息，生成小组专属配置，经人工确认之后完成项目规划、会议整理、风险分析；第一版采用单Agent对话模式，不自动新建独立后台智能体。用来解决小组项目资料分散、计划笼统、分工不合理、会议决议难以落地、变更带来的影响无法评估的痛点。

## 2. 核心需求
- 需求1：提供F01~F05五大功能入口，实现创建专属助手、生成项目计划、整理会议记录、检查进度风险、导出Markdown状态摘要。
- 需求2：助手仅给出建议，项目范围、分工、重大变更必须由小组确认，助手不能替代老师解读课程相关规则。
- 需求3：首轮交付只实现单Agent提示词+RAG检索增强，持久化存储、文件下载、小组共享放到后续迭代，不属于本次交付范围。

## 3. 约束条件 / 限制要求
- 工期要求：按照课程项目交付周期完成首轮版本交付
- 技术限制：第一版为单Agent，不实现后台独立智能体、文件下载、永久存储、消息提醒功能
- 其他要求：输出的状态摘要为纯Markdown文本，支持复制恢复上下文，不需要账号隐私系统

## 4. 相关配置参数
> 项目模式：单Agent + RAG检索增强
> 交互规则：信息采集每轮追问最多15个问题，不猜测缺失信息，缺失字段标记待确认
> 配置状态分为：草案 / 已确认两种状态
