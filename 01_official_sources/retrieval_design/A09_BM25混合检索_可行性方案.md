# A09 EngiMate 检索设计与可行性结论

版本：A-v0.1｜日期：2026-11-05｜作者：组员 A 的 AI 辅助实验，待本人和团队复核｜范围：不同课程的学生工程项目｜状态：本地检索原型已验证；XIPU AI 接入与端到端效果未验证。

## 决策

BM25 在本地可运行且值得作为型号、编号和术语查询的候选；向量检索与 RRF 混合检索也已在本地运行。现有小样本**不能证明混合方式一定比 BM25 或平台原有检索更好**。建议先核查 XIPU AI 是否开放检索模式、索引、来源筛选和输出轨迹，再用同一项目资料进行受控对比；在确认前，不改变对外能力承诺，也不声称平台已接入 BM25。

## 检索路径建议

用户选定项目 → 只读取有权使用、版本适用的项目材料及经审核的通用方法 → 解析并切块 → 若平台允许，比较 BM25、向量或两路融合 → 必要时针对多份来源分别检索 → 汇集证据并标注来源 → Agent 回答与不确定性说明。项目筛选与真正身份授权是不同功能；前者不能证明后者存在。

对需要比较多份资料的问题，可尝试将任务拆为明确的子查询，分别寻找每份材料，再核对是否覆盖所有必要证据；如果平台支持来源过滤，可以作为附加选项。每增加一次检索均可能增加成本与延迟。这个方案尚未在 XIPU AI 验证，不能承诺自动拆问或自动工具调用。

## 已执行的离线证据

完整方法、标注、两轮原始结果和复现命令见 [本地实验](../../05_testing/retrieval_tests/offline_benchmark/README.md)。

- 人工虚构材料：16 道有证据题、2 道无答案题；3 个随机种子、3 个干扰规模、2 个本地项目筛选条件、3 种方法。每次完整实验生成 972 条记录，重复执行后前 5 名排序一致。重复相同实验仅验证复现，不等于增加独立真实用户样本。
- 在最大 200 个虚构干扰单元且开启本地项目筛选时，Top 3 全部证据覆盖：BM25 48/48、中文向量 33/48、RRF 混合 39/48；该人工语料中混合未超过 BM25，不能推广到真实资料。
- 现有团队文件：B01—B05、A03、A06 共 7 份按标题切出的 41 个本地段落，12 题；三种方法的 Top 3 全部证据覆盖均为 11/12。三种方法都未同时找齐比较 B03/A06 的必要段落。
- 该失败题的事后诊断：参考目标段落手动拆成两个含已知答案线索的问题，每题各取前 3 个，合并后本地三种方法都找到两份证据；这是单题、事后、两次调用的机制演示，不是盲测，不证明自动拆问已实现或对新问题有效。

这两个语料均为小样本；人工标签尚未独立复核，合成干扰规则简单，本地模型和切块方式可能不同于平台。离线结果不包含 Agent 生成、错误拒答、安全授权或真实使用表现。

## 推荐的 XIPU AI 后续验证

1. 主搭建人查看实际知识库和 Agent 配置，记录可选检索名称、模型、分块方式、Top K、阈值、来源过滤和调用轨迹；只有官方说明或界面明确时才能称某模式为 BM25。Lab 3 p.6 截图显示 `Vector search` 和 Hit test 结果，但不能证明当前账号支持 BM25、RRF 或外部检索。
2. 在允许的隔离测试环境导入对应的虚构测试资料与经团队审阅的唯一方法主版本；A04/A08 的题目和标准答案不导入被测库。确认解析完成并记录知识库及文件版本。
3. 如果平台允许独立选择，依次比较词法/BM25、向量和混合模式：固定资料、项目范围、分块、问题和 Top K；对每次返回保存完整片段及排序。无法固定或观察的条件必须如实记录，无法分离模式时标为无法完成受控对比。
4. 分别计算有答案题的首个相关排名及多来源全覆盖；无答案题单独检查 Agent 是否编造；对同一批问题重复测试并保存完整 Agent 答案和可见轨迹。实际调用时未知上下文不得用单独 Hit test 代替。
5. 依据真实测试选择可用方案：保留错误编号、来源冲突和无答案的失败实例；若混合模式在相关任务、延迟或成本上没有可验证收益，则继续使用更合适的可用模式，而非因算法名字更复杂就启用。
