
# A 组员：来源、课程要求与检索质量

状态：资料与测试设计初稿，待小组审阅；尚无 XIPU AI 的检索或 Agent 实测结论。版本：A-v0.3；整理日期：2026-11-05。

本目录为 EngiMate 的来源核对、规则追踪和集成提供依据。EngiMate 面向不同工程课程的项目：**通用工程方法、当前用户项目的课程事实、团队建议和虚构测试材料必须区分**。ISA104 是开发本产品的课程，不是所有未来用户项目的默认要求。

## 交付边界

本目录是**开发资料**，不是一整包直接上传的通用知识。A03 和 A06 可在小组确认、解决与 B 文件的冲突并选定主版本后考虑作为通用知识候选；本课程要求和评分细则仅用于 ISA104 的本组项目上下文；来源登记、交叉审阅、测试答案和虚构冲突文件不进入生产知识库。若要让未来用户使用自己的课程规则，必须另外提供该用户有权使用的资料并验证项目边界。

课程原件位于课程平台或本地课程文件，本次没有将课程 PDF 正文重新发布到公开仓库；来源目录提供文件名、页码及 SHA-256 用于核对版本。
